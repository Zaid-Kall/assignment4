# Task Manager Application - CMP309 Web Programming

## Project Description
This is a simple Task Manager web application built for the Web Programming course. The project demonstrates core frontend development concepts using modern JavaScript (ES6+), DOM manipulation, and browser local storage.

## Files Structure
- **index.html**: Main HTML layout and user interface.
- **styles.css**: CSS styling for the application interface.
- **taskManager.js**: Contains the `Task` and `TaskManager` classes to handle task logic (add, delete, toggle).
- **api.js**: Handles asynchronous simulation for saving and loading data from `localStorage`.
- **main.js**: Connects everything together, handles DOM events, and updates the UI dynamically.

## How to Run
1. Open `index.html` in any web browser.
2. Or run it using a local development server (like Live Server in VS Code).
